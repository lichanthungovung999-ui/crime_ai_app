# AI Crime Analyzer

## Description
This project uses Google's Gemini AI to analyze crime scene information and generate a forensic report.

## Features
- Upload crime scene image
- Enter case details
- AI-powered analysis
- Suspect evaluation
- Evidence summary

## Technologies Used
- Python
- Tkinter
- Google Gemini API
- Pillow
- Streamlit

## How to Run

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Run the program:

```bash
python main.py
```
